# Paradigmas de Programação

Disciplina ministrada pelo professor Kláudio, com o objetivo de explorar diferentes paradigmas de programação e ampliar a compreensão sobre estilos e técnicas de desenvolvimento de software.

Durante o curso, foram estudados conceitos fundamentais dos principais paradigmas, como:

- Programação imperativa
- Programação orientada a objetos
- Programação funcional
- Programação lógica

Além da parte teórica, a disciplina propôs um desafio prático: o desenvolvimento de um projeto de jogo utilizando uma linguagem de programação pouco conhecida. Para isso, foi escolhida a linguagem **D**, permitindo a experimentação de novas sintaxes, recursos e abordagens de programação.

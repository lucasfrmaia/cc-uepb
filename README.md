# Repositório de Atividades e Projetos – Curso de Computação (UEPB)

Este repositório tem como objetivo documentar todas as atividades, exercícios, projetos e códigos desenvolvidos ao longo do curso de Computação da Universidade Estadual da Paraíba (UEPB). Aqui você encontrará uma coletânea organizada de materiais produzidos em diversas disciplinas, servindo como registro do aprendizado, consulta futura e compartilhamento de conhecimento.

## Como Navegar

Basta acessar o diretório correspondente à disciplina de interesse para encontrar os materiais relacionados. Cada pasta contém arquivos de código, resoluções de exercícios e projetos.
